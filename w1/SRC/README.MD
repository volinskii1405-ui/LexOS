# Markdown in LexOS

LexOS Web shows **Markdown** too: a `.MD` file opened from Files (or
over `http://` and `https://`) is turned into a page - *headings*,
**bold**, *italic*, `code`, links and the rest.

## Lists

- The desktop: windows, icons, Lex the cat
- Files: drag, copy, **Properties**, the trash
  - nested items
  - and more of them
- Notepad: tabs, colors, undo

1. Open Files
2. Double-click a `.MD` file
3. Read it here

## Code

```
int main(void)
{
    puts("Hello, LexOS!");
    return 0;
}
```

> A quote: what LexOS Web can't do yet - CSS, JavaScript,
> forms - it says so.

| Key    | What it does         |
|--------|----------------------|
| Ctrl+S | Save (in Notepad)    |
| F5     | Reload (here)        |
| Esc    | Quit                 |
