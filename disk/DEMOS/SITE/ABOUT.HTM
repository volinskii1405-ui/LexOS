About LexOS Web

LexOS Web is apps/browser.c - one C file, built into /APPS/BROWSER.APP. It runs like every other LexOS program: in its own 4MB, in ring 3, asking the kernel for what it needs through int 0x80:

  • open/read - pages and pictures on this disk (with a path: /DEMOS/SITE/LEX.BMP)
  • fetch - pages from the web: the kernel's own TCP/IP and HTTP, the same as wget
  • mouse - where the pointer is in its window, the buttons, the wheel
  • font - the system's 8x16 font, Russian and Spanish letters included
  • gfx_mode_ex / gfx_blit - an 800x600 picture in a window on the desktop

What it understands

  1. Headings h1-h6, paragraphs, br, hr
  2. Bold, italic, underlined, colored text
  3. Links (relative ones too: ../SITE/./INDEX.HTM)
  4. Lists, nested:
    • bullets
    • and numbers
  5. Pictures: img with a .BMP (8, 24 or 32 bits)
  6. <pre>, <blockquote>, <center>, tables as rows
  7. Entities: &amp; © «quotes» — and UTF-8

Scripts and styles are skipped: this is the web as it was in 1995.
