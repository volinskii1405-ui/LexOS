STARTUP - programs that start with the desktop

Whatever program is in this folder (/DESKTOP/STARTUP) starts by itself
each time the desktop does - after the boot, and after Log out.

  * a program (.APP, .COM, .BIN): put a copy of it here
    (Files: right-click it, Copy to...)
  * or a shortcut: a .LNK file whose text is the program's path,
    for example FIRE.LNK with the line /APPS/FIRE.APP

This file isn't a program, so it's left alone.
